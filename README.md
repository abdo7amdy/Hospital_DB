Hospital_DB 🏥💾
Hospital_DB is a comprehensive database system designed to manage hospital operations efficiently. It includes structured tables, relationships, and queries to handle patients, doctors, appointments, medical records, billing, and more.

Features 📌
✔ Patients Management – Store and retrieve patient details, medical history, and diagnoses.
✔ Doctors & Staff – Manage doctor schedules, specialties, and assignments.
✔ Appointments System – Track patient appointments with doctors.
✔ Medical Records – Maintain prescriptions, treatments, and test results.
✔ Billing & Payments – Handle patient invoices and payment records.
✔ Efficient Queries – Optimized SQL queries using joins, indexing, and stored procedures.

Tech Stack 🛠
🔹 Database: SQL Server 
🔹 Queries & Procedures: SQL, Stored Procedures, Triggers
🔹 Tools: SQL Management Studio
